   # What version one does
   - Reads paperwork: spreadsheets and photographed invoices.
   - Squeezes every line into six facts: product code, weight (kg), value (£), date, country, supplier.
   - Adds up covered imports over the last 12 months, against £50,000.
   - Emails a calm warning at 70% and an urgent one at 90%.
   - Estimates carbon per shipment using the EU's official fallback numbers, badged ESTIMATE.

   # What it never does
   - Never files anything with the government.
   - Never gives legal advice.
   - Never decides a borderline product code alone.
   - Never says "you are compliant".
